# Step 01: Explore Legacy Node 16 App
# ==============================================

## Node Version Check
Current Node: v24.14.1 (target: Node 22 patterns)
Package.json engines: ">=16.0.0"

## Legacy Codebase Analysis

### Architecture
- Express 4.18.2 web app with EJS templates
- SQLite via better-sqlite3 (synchronous)
- Session-based auth with bcryptjs
- 7 route modules: index, auth, hackathons, teams, participants, submissions, judging

### Node 16 / CommonJS Patterns Found
1. **CommonJS require/exports** - All 11 source files use `require()` and `module.exports`
2. **var declarations** - 20+ instances of `var` instead of `const`/`let`
3. **Separate body-parser** - Using deprecated standalone body-parser package
4. **Callback-style functions** - `function(req, res, next)` instead of arrow functions
5. **moment.js** - Using moment (deprecated) for date formatting
6. **Synchronous bcrypt** - `bcrypt.hashSync()` and `bcrypt.compareSync()`
7. **No async/await** - Entire codebase uses synchronous patterns
8. **Old nodemon** - v2.0.22 in devDependencies
9. **Hardcoded secrets** - Session secret in source code
